================================================================================
  ALGORITHM VERIFICATION
================================================================================

Progressive Lockout Exponential Backoff:
- 5 failed attempts → 1 second delay (2^(5-5) = 1)
- 6 failed attempts → 2 second delay (2^(6-5) = 2)
- 7 failed attempts → 4 second delay (2^(7-5) = 4)
- 8 failed attempts → 8 second delay (2^(8-5) = 8)
- Reset: 15 minutes of inactivity OR successful login
Status: ✓ IMPLEMENTED

Refresh Token Replay Detection:
- Each token pair has family_id UUID
- Multiple uses in same family within 5 minutes = REPLAY ATTACK
- Action: Revoke entire family, log audit event, reject request
Status: ✓ IMPLEMENTED

Session Tracking:
- Device fingerprint: SHA256(user_agent + ip)
- Max 5 active sessions per user per 30 days
- 6th session creation → auto-revoke oldest session
- Remote logout: revoke_session(user_id, session_id)
Status: ✓ IMPLEMENTED

2FA TOTP:
- Generate random Base32 secret with pyotp.random_base32()
- QR URI format: otpauth://totp/email@domain?secret=...&issuer=Whetzy
- 10 one-time backup codes (hex encoded, SHA256 hashed in DB)
- Backup codes: one-time use (removed after verification)
- TOTP window: ±1 (allows 30-second drift)
Status: ✓ IMPLEMENTED

Audit Log:
- Immutable append-only (INSERT only, no UPDATE/DELETE)
- Logged actions: login_{success,failed,lockout}, logout, password_{change,reset_*},
  2fa_{enabled,disabled,backup_code_used}, session_{created,revoked,evoked},
  refresh_token_issued, refresh_replay_attack, admin_*, account_{deleted,exported}
- Indexes: user_id, action, timestamp
Status: ✓ IMPLEMENTED
