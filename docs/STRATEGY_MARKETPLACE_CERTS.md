# Neurium — Estrategia: Marketplace de Certificaciones

> Originado en sesión estratégica 2026-09-07. Captura la dirección B2B/marketplace que
> extiende el modelo de negocio más allá de los tracks propios de Python→AI Engineering.

---

## 1. El concepto: Plataforma de infraestructura adaptativa

Neurium no es solo una plataforma de aprendizaje — es la infraestructura sobre la que
cualquier creador puede construir su propio bootcamp adaptativo sin saber programar.

### Niveles de la propuesta

**Nivel 1 — Usuario crea su track personal**
Sube preguntas desde JSON, PDF, o foto. El motor (FSRS + Elo + BKT) se aplica automáticamente.
El usuario tiene su propio bootcamp personalizado con el motor más sofisticado del mercado.

**Nivel 2 — Creador construye bootcamp para otros**
El creador define estructura de módulos, preguntas, prereqs y precio. Neurium hereda automáticamente:
- Motor adaptativo completo (FSRS/Elo/BKT/bandit)
- Gamificación (XP, ligas, badges, streaks)
- Tutor AI que explica respuestas incorrectas
- Exámenes de maestría por módulo
- Certificado de completación
- Analytics por alumno

**Nivel 3 — Marketplace con comisión**
Bootcamp de pago → creador recibe 70–80%, Neurium retiene 20–30%.

### Posicionamiento estratégico
No competir con Teachable o Udemy — **ser la capa de inteligencia adaptativa que ellos no tienen**.
Teachable/Udemy son lineales: el alumno A y el alumno B ven el mismo contenido en el mismo orden.
Neurium se adapta individualmente. Ese es el argumento de venta del creador a su audiencia.

## 3. Las 5 certificaciones prioritarias para Neurium

En este orden por ROI de desarrollo:

### 1. AWS Cloud Practitioner (CLF-C02) — Construir primero
**Por qué:** Es el entry point de AWS. El usuario que quiere SAA empieza aquí. Es el funnel
hacia certificaciones más avanzadas. Temario público, preguntas verificables, audiencia enorme.

### 2. CompTIA Security+ — Construir segundo
**Por qué:** 48% de todos los listings de cybersecurity. Sin prerequisitos técnicos fuertes —
accesible para más usuarios. Temario estructurado y público (Exam Objectives PDF oficial).

### 3. AWS Solutions Architect Associate — Construir tercero
**Por qué:** 80% de los job postings de cloud la requieren. La más pedida del mercado.
Alta disposición a pagar por preparación de calidad (el examen cuesta $300).

### 4. Azure AI Engineer Associate (AI-102) — Construir cuarto
**Por qué:** Conecta directamente con el track propio de AI Engineering. El usuario que termina
Python→AI Engineering tiene el conocimiento base para esta cert. Es el upsell natural.

### 5. Google Professional ML Engineer — Construir quinto
**Por qué:** Completa el trío cloud para ML. Con AWS ML + Azure AI-102 + Google ML se cubre
el 90% del mercado de AI Engineering certificado.

## 4. Ventaja competitiva específica en certificaciones

### Lo que hace la competencia (Udemy, Whizlabs, MeasureUp, ExamTopics)
Te da el **mismo simulacro de examen a todos**. 200 preguntas en orden fijo. El usuario memoriza
el banco de preguntas — no aprende, memoriza.

### Lo que hace Neurium
- BKT sabe exactamente qué dominios del examen tienes débiles
- FSRS programa el repaso de cada concepto en el momento óptimo antes del examen
- El motor nunca repite la misma pregunta hasta que hayan pasado días
- El examen de práctica se genera dinámicamente — nunca es el mismo
- El tutor AI explica por qué fallaste una pregunta basándose en tu historial completo

**Argumento de venta:** "El examen de AWS SAA cuesta $300. Reprobarlo cuesta otros $300 y 3 meses
de tu tiempo. Neurium garantiza que llegas dominando el material, no memorizando preguntas."

## 5. Modelo de negocio expandido

```
FUENTES DE INGRESO:

1. Suscripciones B2C (ya en spec)
   Free / Pro $9.99 / Pro+ $19.99

2. Comisión de bootcamps de pago (NUEVO)
   20–30% de cada venta de bootcamp de creador

3. Plan Creator Pro (NUEVO)
   $29.99/mes → analytics avanzados, dominio personalizado,
   certificados con su marca, prioridad en búsqueda

4. B2B institucional (NUEVO)
   Empresas que crean bootcamps internos para onboarding
   $200–$500/mes por empresa
```

### Efecto de red
```
Más creadores → más bootcamps → más variedad
      ↓
Más variedad → más usuarios encuentran algo relevante
      ↓
Más usuarios → más datos para el motor adaptativo
      ↓
Motor más preciso → mejor experiencia → más retención
      ↓
Más retención → más ingresos para creadores
      ↓
Más creadores quieren estar en Neurium
```

## 7. Orden de implementación recomendado

**Antes de construir el marketplace de creadores:**
Validar Neurium con tracks propios hasta 500 usuarios activos con datos reales de retención.
El marketplace de creadores es Fase 4+ del roadmap — no antes de tener tracción probada.

**Cuando lanzar el marketplace:**
Con 500+ usuarios activos, el outreach a creadores hispanos (MoureDev, Fazt, Pelado Nerd)
cambia de "prueba mi app" a "construye tu bootcamp adaptativo en mi plataforma con 500 usuarios
activos". Esa es una propuesta completamente diferente.

**Para las certificaciones propias de Neurium:**
Construir los 5 bootcamps prioritarios antes del marketplace de creadores, como contenido propio.
Esto resuelve el problema del huevo y la gallina: llegar al mercado con contenido día 1.

## 8. Riesgos identificados

| Riesgo | Probabilidad | Mitigación |
|---|---|---|
| Calidad de contenido de creadores | Alta | Sistema de rating + quality gate de Claude antes de publicar |
| Complejidad de implementación del panel Creator | Media | Es Fase 4+ — no MVP |
| Moderación de contenido (copyright, respuestas incorrectas) | Media | Políticas claras + pipeline de revisión |
| Costos de Claude API para generación de preguntas | Alta | Routing estricto: Haiku para volumen, Opus solo para revisión técnica |
