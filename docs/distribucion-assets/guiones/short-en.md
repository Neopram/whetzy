# Script — Short-Form Video (60s) — English

## Objective
Viral TikTok/YouTube Shorts. Quick hook for career-switchers. Target: 18-35, social media native.

## Structure (Tight 60 seconds)

### Hook (0:00-0:10)
- **Visual:** Big title card: "Want to learn to code without wasting time?"
- **Quick narration:** "Yes. Actually learn it."
- **SFX:** Whoosh, beat drop

### Problem + Solution (0:10-0:45)
- **Visual:** Split screen montage
  - **Left:** Generic competitor (slow, boring)
  - **Right:** Whetzy (fast, right questions)
- **Narration:** "Every question is picked by an adaptive engine, based on what you already know."
- **No time-saving stat:** v1's "47% less time" and "500 unique questions" had no source (red line: no figure without a source). Use only the landing figures (35 tracks · 10,989 questions on 2026-09-30, read them from `catalog.ts` on the day)
- **Visual:** Progress bar filling fast, fire emoji (streak)

### CTA (0:45-0:60)
- **Visual:** App screen, brilliant "Start Free" button
- **Narration:** "Start free today. No credit card."
- **Overlay:** `whetzy.com` + `YT-EN-SHORT` (campaign code prominent)
- **SFX:** Positive chime, fade to black

## Technical Notes
- **Duration:** 58-62 seconds
- **Aspect ratio:** 9:16 (vertical for TikTok/Shorts)
- **Codec:** H.264, 4000 kbps
- **Audio:** Upbeat, trending sound (Incompetech or licensed), fast cuts to beat
- **Campaign Code:** `YT-EN-SHORT`
- **Text:** Large, bold, high contrast (white on dark)
- **Subtitles:** Hard-coded EN (no autoplay audio dependency)
