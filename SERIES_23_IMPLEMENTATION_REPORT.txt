### 1.1 Admin Endpoint Updates
**File:** `backend/app/api/v1/endpoints/admin.py`

All admin endpoints now support language segment filtering:

#### Metrics Endpoints
- `/metrics/users?segment=all|es|en` — DAU/WAU/MAU by language
- `/metrics/funnel?segment=all|es|en` — Conversion funnel (signup → active 7d → active 1d)
- `/metrics/ttfq?segment=all|es|en` — Time-to-first-question percentiles

#### Revenue Endpoints
- `/revenue/mrr?segment=all|es|en` — Monthly recurring revenue by language
- `/revenue/conversions?segment=all|es|en` — Conversion rates
- `/revenue/churn?segment=all|es|en` — Churn analysis

#### Economy Endpoints
- `/economy/credits?segment=all|es|en` — Credit ledger filtered by language
- `/economy/referrals?segment=all|es|en` — Referrals by referrer language
- `/economy/k-factor?segment=all|es|en` — K-factor (viral coefficient) by segment

**Implementation Details:**
- Each endpoint builds language WHERE clause conditionally
- Segment parameter defaults to "all" (backward compatible)
- Queries properly join StudySession → User to access language field
- All responses include "segment" field for transparency

### 2.1 Currency Configuration Module ✓ DONE
**File:** `frontend/src/lib/currency.ts` (NEW)

- Type definitions for Language, Currency
- getCurrencyForLanguage(language) → EUR|USD
- getPricingPlans(language) → localized pricing array
- formatPrice(amount, currency, language) → "€9,99" or "$9.99"

**Pricing Logic:**
- Spanish (ES) → EUR: Plus €9.99, Pro €19.99
- English (EN) → USD: Plus $10.99, Pro $21.99

**Usage in LandingScreen:**
```tsx
import { getPricingPlans } from '../lib/currency';

const plans = getPricingPlans(lang); // 'es' or 'en'
// plans[1].price = 9.99 or 10.99 depending on language
```
